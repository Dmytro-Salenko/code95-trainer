# Driver95

**Бесплатный тренажёр для подготовки к экзамену Code 95 — квалификации водителей категории C/D в ЕС.**

🌐 **[driver95.eu](https://driver95.eu)**

---

## О проекте

Driver95 — прогрессивное веб-приложение (PWA) без регистрации и оплаты. Работает офлайн, сохраняет прогресс локально и поддерживает 8 языков. Приложение предназначено для профессиональных водителей, которые готовятся к сдаче квалификационного экзамена Code 95.

---

## Возможности

- **298 вопросов** по тематике Code 95 с правильными ответами и пояснениями
- **5 режимов обучения:**
  - **Обучение** — только непройденные вопросы; правильно отвеченные исключаются на лету
  - **Экзамен** — 40 случайных вопросов, формат реального экзамена
  - **Ошибки** — повторение неправильно отвеченных вопросов
  - **Избранное** — вопросы, отмеченные пользователем закладкой
  - **Случайные** — все вопросы в случайном порядке
- **Прогресс** сохраняется в `localStorage` — без сервера и авторизации
- **PWA** — устанавливается на главный экран, работает офлайн через Service Worker
- **Тёмная и светлая тема**
- **Ненавязчивая карточка «Поделиться»** — появляется один раз после успешной сессии

## Технологии

- **HTML / CSS / JavaScript** — ванильный стек, без фреймворков
- **Service Worker** — офлайн-кэш, PWA-установка
- **Google Analytics 4** — анонимная продуктовая аналитика
- **Node.js / Express** — сервер для деплоя (опционально; приложение работает и как статика)
- Никаких сторонних UI-библиотек

## Локальный запуск

### Статически (без сервера)

Достаточно открыть `index.html` в браузере или использовать любой статический сервер:

```bash
npx serve .
```

### С Node.js-сервером

```bash
npm install
cp .env.example .env   # настроить переменные окружения
npm start              # запускает server.js на порту 3000
```

По умолчанию сервер доступен на `http://localhost:3000`.

---

## Деплой

Приложение разворачивается как обычный статический сайт. Сервер (`server.js`) опционален — нужен только если требуются серверные маршруты (`/robots.txt`, `/sitemap.xml`, заголовки кэширования).

Рекомендуемые платформы: **Render**, **Railway**, **VPS с nginx**.

Переменные окружения (`.env`):

```
PORT=3000
ADMIN_USERNAME=your_admin_username
ADMIN_PASSWORD=your_secure_password
SESSION_SECRET=your_secret_key
```

> **Важно:** никогда не коммитьте `.env` в репозиторий. Файл добавлен в `.gitignore`.

## Аналитика

Приложение использует Google Analytics 4 (анонимная, GDPR-совместимая).

- Персональные данные не собираются
- Используется постоянный анонимный UUID (`localStorage`)
- Отслеживаются события: запуск теста, ответы, завершение, избранное, прогресс
- Подробнее: [`docs/ANALYTICS.md`](docs/ANALYTICS.md)
